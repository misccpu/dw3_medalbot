# misc_cpu

This is experimental bot with the goal of collecting every bronze, silver, and gold medal in the GBC release of Dragon 
Warrior 3 without using speedup or save states. This project began as a fork of pokebot_gen3 by 40Cakes. I'd love to 
stream the bot completing the run, much like he is doing with his shiny living dex Professor Oak's Challenge. Let's see 
how this develops!
